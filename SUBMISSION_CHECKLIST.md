# Pre-Hard Stop 3 Submission Checklist

## Repository Structure and Organization
- [ ] Repository tree is visible and professional.
- [ ] Naming conventions are documented.
- [ ] Branch strategy is documented.
- [ ] Artifact storage conventions are documented.

## Environment and Reproducibility
- [ ] Tested Python version is recorded.
- [ ] Virtual environment instructions work.
- [ ] `pip install -r requirements.txt` succeeds.
- [ ] `streamlit run app/main.py` succeeds.
- [ ] `pytest -q` succeeds.

## Documentation
- [ ] README is current.
- [ ] Architecture notes are current.
- [ ] CHANGELOG is current.
- [ ] Known issues are current.
- [ ] Engineering log is updated.

## Risk and Issue Management
- [ ] Every risk/issue has an ID.
- [ ] Severity is present.
- [ ] Mitigation/action is present.
- [ ] Owner is present.
- [ ] Status is present.

## Version Control
- [ ] Baseline files are committed.
- [ ] Commit history is visible.
- [ ] `v0.1.0-baseline` tag exists.
- [ ] Tag is pushed to GitHub.

## Runnable Evidence
- [ ] Screenshot of repository tree.
- [ ] Screenshot of Streamlit running.
- [ ] Screenshot of terminal showing application startup.
- [ ] Screenshot of `pytest -q` showing passing test.
- [ ] Screenshot of Git tag or release.

## Sprint Reflection
- [ ] Completed work is described.
- [ ] Blockers are described.
- [ ] Lessons learned are described.
- [ ] Next sprint is clearly stated.

## AI Usage
- [ ] AI usage log is complete and accurate.
- [ ] Every AI-assisted artifact is reviewed and understood before submission.
